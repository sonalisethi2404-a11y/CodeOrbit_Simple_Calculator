
# Simple Calculator

## Project Overview
A simple command-line calculator developed using Python.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero
- Handles invalid inputs
- Supports repeated calculations

## Technologies Used
- Python 3

## Concepts Used
- Functions
- Conditional Statements
- While Loop
- Exception Handling
- User Input

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run:

   python calculator.py
